## I turn ideas into working systems.

I’m a senior software engineer, architect, and engineering leader with decades of experience building products from prototype through production — and leading the teams that ship them.

My background spans internet infrastructure, SaaS, ad tech, mobile, fleet operations, AI agents, automation, and the occasional machine that moves, flashes, sings, prints, scans, or otherwise escapes the browser.

I’m happiest at the intersection of **software architecture, product thinking, and hands-on implementation**: finding the important problem, simplifying it, and shipping something useful.

**Currently interested in:** senior/staff engineering, architecture, CTO/VP/Director-level engineering leadership, and ambitious product work where experienced technical judgment still matters.

## Selected work

### 🎛️ [Panic Backstage](https://github.com/chrisrobison/panic-backstage)
A venue operating system covering the full **inquiry → booking → contract → production → ticketing → settlement** lifecycle.

Built as an API-first, multi-tenant application with PHP 8, MySQL, native Web Components, WebAuthn/passkeys, background jobs, CRM, contracts/e-signature, event syndication, marketing workflows, notifications, reporting, and operational tooling — without requiring a frontend build pipeline.

### 🧠 [agent-orchestrator](https://github.com/chrisrobison/agent-orchestrator)
A browser-only multi-agent framework using **WebLLM + WebGPU**, with SharedWorker-hosted models, agent orchestration, streaming generation, cancellation, telemetry, and Web Component-based visualization. No application backend required.

### 🎸 [BandBrief](https://github.com/chrisrobison/bandbrief)
A deterministic artist intelligence system that aggregates and normalizes data from Spotify, Last.fm, MusicBrainz, Wikipedia/Wikidata, Reddit, Bandcamp, Bandsintown, and other sources to produce booking-oriented artist reports.

### 🤖 [cv2job](https://github.com/chrisrobison/cv2job)
An agentic AI job-search assistant exploring how software can turn a résumé, job data, research, and automation into a more useful job-hunting workflow.

## What I’ve done professionally

- **CTO / hands-on architect:** built and automated operational software for a transportation company, including scheduling, dispatch, GPS/telematics integrations, driver workflows, CRM, maintenance, invoicing, and customer operations.
- **Senior engineering management:** led rich-media and mobile engineering teams at Conversant/Mediaplex, while continuing to architect and ship production systems.
- **Web architecture:** helped build SaaS and browser applications at companies including Mindjet, Food.com, Slip.Net, and others going back to the commercial web’s formative years.
- **Technical leadership:** managed teams of 20+ while remaining comfortable dropping into architecture, debugging, infrastructure, APIs, databases, frontend code, or whatever else is blocking delivery.
- **Builder by default:** software is only one medium. I also build hardware, 3D printers/scanners, robotics projects, audio tools, event-tech systems, and other things that connect bits to atoms.
